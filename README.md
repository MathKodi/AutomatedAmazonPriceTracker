# AutomatedAmazonPriceTracker

Desenvolvi um script em Python que realiza o scraping de páginas da Amazon para monitorar o preço de um produto específico. Utilizando as bibliotecas BeautifulSoup, requests e smtplib, o sistema compara automaticamente o preço atual do item com o valor máximo que estou disposto a pagar. Sempre que o preço do produto atinge ou fica abaixo do valor definido, o script envia um e-mail de alerta para me notificar, garantindo que eu não perca oportunidades de compra com desconto.
